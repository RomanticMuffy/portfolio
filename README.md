## About

A curated guide to the most relevant programming languages and technology stacks in the current dev scene — built entirely with vanilla **HTML**, **CSS**, and **JavaScript**. No React, no frameworks, no build tools. The goal was to deliver a clean, expressive informational experience using raw web standards alone.

The visual identity draws from **Frutiger Aero**, the Windows Vista/7 era UI language, and **Webcore** aesthetics — glossy surfaces, soft glows, translucent layers, and a feeling of the early-2010s internet that never got old.

## About This Guide

Whether you're just starting out or looking to expand your skill set, this guide covers the stacks that actually matter in the current dev landscape. Each section points to honest starting resources, explains why a given language or framework is relevant, and gives you a clear direction without the fluff.

Stacks covered include:

- **JavaScript / TypeScript** — the backbone of the web, from DOM scripting to large-scale apps
- **Python** — the best first language, dominant in data science, ML, automation and backend
- **React / Next.js** — the most widely adopted frontend stack in the industry right now

The popup panel surfaces the broader ecosystem: tools, runtimes, databases, editors, and more — all the things that surround the code itself.

---

## Features

- **Zero dependencies** — pure HTML, CSS, and JavaScript, nothing to install
- **Fully static** — runs directly in the browser, deployable anywhere
- **Custom animations** — hand-written CSS transitions and JS interactions, no animation libraries
- **Glassmorphism & gloss effects** — layered translucency inspired by Vista-era UI
- **Responsive layout** — adapts across screen sizes without breakpoint frameworks
- **Dark aesthetic** — deep backgrounds with luminous accents and soft bloom

### Aesthetic References

The visual identity is rooted in three overlapping aesthetics:

#### Frutiger Aero

Coined after the typeface designer Adrian Frutiger and the era of glossy, nature-infused UI design (roughly 2004–2013). Characterized by: glass-like surfaces, soft gradients, water and sky motifs, optimistic colors, and a sense of digital "cleanness."

<img width="1920" height="1161" alt="frutiger-aero" src="https://github.com/user-attachments/assets/281392eb-e2e6-4bcf-a741-f543a12ae6a7" />

<br/>

<img width="1280" height="720" alt="1742978370834" src="https://github.com/user-attachments/assets/b4fcb601-ba37-4abd-a1b6-7508af47c516" />

#### Windows Vista / 7 UI

The Aero Glass interface from Windows Vista and Windows 7 is a direct reference — the frosted taskbar, the translucent window chrome, the glow on hover states, the soft drop shadows, and the ultra-smooth bezels. This era of UI design had a warmth and materiality that flat design erased.

<img width="1024" height="768" alt="windows_7" src="https://github.com/user-attachments/assets/1ca696a5-27ff-4448-9809-64d67233bfde" />

---

#### Webcore

An internet aesthetic rooted in the visual culture of the early-to-mid 2000s web — pixel fonts, lens flares, translucent panels, glowing outlines, and skeuomorphic detail. More emotional than functional. Less UI, more vibe.
